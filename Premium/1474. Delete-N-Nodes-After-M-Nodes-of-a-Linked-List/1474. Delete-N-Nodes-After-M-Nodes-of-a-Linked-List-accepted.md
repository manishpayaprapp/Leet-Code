# 1474. Delete N Nodes After M Nodes of a Linked List

## Problem Statement
Given the head of a linked list and two integers `n` and `m`, traverse the linked list and delete `n` nodes after skipping `m` nodes repeatedly until the end of the list.

## Approach
- Initialize `curr` to `head`.
- Traverse and keep `m` nodes.
- Skip the next `n` nodes.
- Connect the last kept node to the next remaining node.
- Repeat until the end of the list.

## Code (C++)

```cpp
/* Structure of Linked List Node
class ListNode {
  public:
    int data;
    ListNode* next;

    ListNode(int val) {
        data = val;
        next = nullptr;
    }
};*/

class Solution {
  public:
    void linkDelete(ListNode* head, int n, int m) {
        // code here
        ListNode* curr = head;

        while(curr != nullptr){
            int counter = 0;
            ListNode* prev = nullptr;

            while(counter < m && curr != nullptr){
                counter ++;

                prev = curr;
                curr = curr -> next;
            }

            counter = 0;

            while(counter < n && curr != nullptr){
                counter ++;
                curr = curr -> next;
            }

            prev -> next = curr;
        }
    }
};
