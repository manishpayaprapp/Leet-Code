# 708. Insert into a Sorted Circular Linked List

## 📝 Problem

Given a circular linked list of `n` nodes that is sorted in ascending order, insert a new node with a given value `insertVal` into the list so that it remains a sorted circular linked list.

The given list may contain duplicates, and the new value may be inserted anywhere that preserves the sorted order.

If the list is empty, create a new circular linked list containing the new node and return it.

Otherwise, insert the new node into the appropriate position and return the original head.

### Requirements

- Maintain the sorted order of the linked list.
- Preserve the circular structure.
- Handle duplicate values.
- Handle insertion at the beginning, middle, or end of the sorted order.
- Handle lists where all nodes contain the same value.

## 📌 Examples

### Example 1

**Input:**

```text
head = [3, 4, 1], insertVal = 2
```

**Output:**

```text
[3, 4, 1, 2]
```

**Explanation:**

Insert `2` between `1` and `3`.

The resulting circular linked list is:

```text
3 -> 4 -> 1 -> 2
^              |
|______________|
```

The returned head remains the original node with value `3`.

### Example 2

**Input:**

```text
head = [], insertVal = 1
```

**Output:**

```text
[1]
```

**Explanation:**

The list is empty, so create a new node whose `next` pointer points to itself.

### Example 3

**Input:**

```text
head = [1], insertVal = 0
```

**Output:**

```text
[1, 0]
```

**Explanation:**

Insert `0` after the existing node. The list remains circular.

## 💡 Approach: Single Traversal

We can solve this problem by traversing the circular linked list and identifying the correct insertion position.

Since the list is circular, there is no `nullptr` at the end. We must stop when we return to the original head.

There are three main insertion cases.

### Case 1: Empty List

If `head == nullptr`, create a new node and make it point to itself.

```cpp
newNode->next = newNode;
return newNode;
```

### Case 2: Normal Insertion

Find two consecutive nodes such that:

```text
curr->val <= insertVal <= next->val
```

Insert the new node between them.

For example:

```text
1 -> 3 -> 5
```

Insert `4`:

```text
1 -> 3 -> 4 -> 5
```

### Case 3: Circular Boundary

The circular boundary occurs when the current node contains the largest value and the next node contains the smallest value.

```text
curr->val > next->val
```

Insert the new value at this boundary if:

```text
insertVal >= curr->val || insertVal <= next->val
```

For example:

```text
3 -> 4 -> 1 -> 3
```

Insert `5`:

```text
3 -> 4 -> 5 -> 1 -> 3
```

### Case 4: All Nodes Have the Same Value

If no suitable position is found after one complete traversal, insert the new node anywhere in the circular list.

This handles cases where all existing nodes contain the same value or where the new value can be inserted at any position without violating the sorted order.

## 💻 C++ Solution

```cpp
/*
Definition for a Node.
class Node {
public:
    int val;
    Node* next;

    Node() {}

    Node(int _val) {
        val = _val;
        next = nullptr;
    }

    Node(int _val, Node* _next) {
        val = _val;
        next = _next;
    }
};
*/

class Solution {
public:
    Node* insert(Node* head, int insertVal) {

        Node* newNode = new Node(insertVal);

        // Case 1: Empty circular linked list
        if (head == nullptr) {
            newNode->next = newNode;
            return newNode;
        }

        Node* curr = head;

        while (true) {
            Node* next = curr->next;

            // Case 2: Normal insertion between sorted nodes
            if (curr->val <= insertVal &&
                insertVal <= next->val) {
                break;
            }

            // Case 3: Insertion at the circular boundary
            if (curr->val > next->val &&
                (insertVal >= curr->val ||
                 insertVal <= next->val)) {
                break;
            }

            curr = curr->next;

            // Case 4: Completed one full traversal
            if (curr == head) {
                break;
            }
        }

        // Insert the new node
        newNode->next = curr->next;
        curr->next = newNode;

        // Preserve the original head
        return head;
    }
};
```

## 🔍 Dry Run

Consider the circular linked list:

```text
3 -> 4 -> 1 -> back to 3
```

Insert:

```text
insertVal = 2
```

### Step 1: Initialize Pointers

```text
curr = 3
next = 4
```

Check the normal insertion condition:

```text
3 <= 2 <= 4
```

This is false.

Move `curr` to the next node.

### Step 2: Move to the Next Node

```text
curr = 4
next = 1
```

Check the normal insertion condition:

```text
4 <= 2 <= 1
```

This is false.

Check the circular boundary condition:

```text
4 > 1
```

This is true.

Now check:

```text
2 >= 4 || 2 <= 1
```

This is false.

Move to the next node.

### Step 3: Find the Correct Position

```text
curr = 1
next = 3
```

Check:

```text
1 <= 2 <= 3
```

This is true.

Therefore, insert the new node between `1` and `3`.

### Step 4: Update Pointers

```cpp
newNode->next = curr->next;
curr->next = newNode;
```

### Final Circular Linked List

```text
3 -> 4 -> 1 -> 2 -> back to 3
```

The original head remains `3`.

## ⏱️ Complexity Analysis

### Time Complexity: O(N)

In the worst case, we traverse the entire circular linked list once to find the insertion position.

### Auxiliary Space Complexity: O(1)

We use only a constant number of pointers.

The newly allocated node requires O(1) space and is part of the required output.

Here, `N` is the number of nodes in the original circular linked list.

## ⚠️ Common Pitfalls

### 1. Forgetting the Empty List Case

A new node must point to itself when the list is empty.

```cpp
newNode->next = newNode;
```

### 2. Ignoring the Circular Boundary

The largest and smallest values are adjacent in a circular linked list.

Always check:

```cpp
curr->val > next->val
```

### 3. Forgetting Duplicate Values

Use inclusive comparisons:

```cpp
curr->val <= insertVal &&
insertVal <= next->val
```

This allows duplicate values to be inserted correctly.

### 4. Infinite Loops

A circular linked list never reaches `nullptr`.

Stop after one complete traversal:

```cpp
if (curr == head) {
    break;
}
```

### 5. Returning the Wrong Head

For a non-empty list, return the original `head`.

```cpp
return head;
```

The problem does not require changing the head when the inserted value is smaller than the current head.

### 6. Lists with Identical Values

For a list such as:

```text
3 -> 3 -> 3 -> back to 3
```

Insert `2`.

No normal insertion or circular-boundary condition may match. After one complete traversal, insert the new node at the current position.

The resulting list remains circular and sorted.

## 🎯 Key Takeaways

- Traverse the circular linked list using a loop.
- Identify the normal sorted insertion position.
- Handle the boundary between the maximum and minimum values.
- Allow duplicate values using inclusive comparisons.
- If no position is found after one complete traversal, insert anywhere.
- Preserve the original head for non-empty lists.
- Handle an empty list by creating a self-loop.

The solution runs in **O(N) time and O(1) auxiliary space**.
